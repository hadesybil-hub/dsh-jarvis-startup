# Third-party sources and assets

## Startup plugin integration — MIT

The host/client integration and initial startup plugin structure derive from
[6shenhonghong9/dsh-startup-screen](https://github.com/6shenhonghong9/dsh-startup-screen),
version 1.1.2. Copyright (c) 2026 沈宏宏. Its MIT notice is preserved in LICENSE.

The native adaptation targets the DeepSeek Harness Desktop 0.2.1-rc.3 shell,
whose packaged manifest declares MIT. Patch anchors contain small excerpts from
that shell. The DSH application, dependencies, executables, original ASAR and
patched ASAR are not distributed by this repository.

## Speech — generated by each user

No generated Microsoft speech recordings are included in Git. `generate-audio.py`
uses [edge-tts](https://github.com/rany2/edge-tts) to access Microsoft Edge's online
speech service, then FFmpeg for local processing. The service's applicable terms
are separate from the MIT license on this repository. Check them for your use or
redistribution of generated recordings. No actor recordings, movie audio or
voice-cloning models are included.

## Build dependency

Native ASAR operations use [@electron/asar](https://github.com/electron/asar), MIT,
pinned to 4.2.0 through package.json and package-lock.json. Dependency notices are
provided by the installed packages. Node modules and Python environments are not
committed.
